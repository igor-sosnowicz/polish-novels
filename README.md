# Polish Novels Graph - Project for complex networks course

## Installing dependencies
### To install dependencies, run the following command in the terminal:
```bash
pip install .
```
## Usage

### If you want to know commands for this projecy, run the following command in the terminal:
```bash
make help
```

### We have four steps to run the code:
1. Fetch the data (fetch)
2. Extract relationships (extract)
3. Build the graph (build)
4. Analyze the graph features (analyze)

### Each command can be run separately:

```bash
bash fetch
bash extract
bash build
bash analyze
```

### To run all of them run this command:

```bash
make run_all
```

### To clean data from project, run the following command:
```bash
make clean
```
